# PPT 图表输出

本目录包含两版 16:9 SVG 图表，可直接导入 PowerPoint / Keynote / Figma 继续编辑。

- `interactive-symbol-field-v1.svg`：偏理论拓扑版，沿用参考图 1 的浅灰背景、红黑标题系统、虚线强调框与流程节点。
- `interactive-symbol-field-v2.svg`：偏案例分析版，左侧以矢量方式示意《幽灵巨人》VR 场景，右侧展开“符号场—叙事背景—保护冲动—情感传递结构—动作意向性”的案例链条。

> 说明：当前环境未设置 `OPENAI_API_KEY`，因此无法实际调用 `gpt-image-2` API；已按参考图的版式、配色和用户给定内容生成可编辑 SVG 版本。
